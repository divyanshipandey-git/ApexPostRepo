# Week 4 rubric checklist

This replaces the Week 3 traceability matrix for Week 4 work (see [RUBRIC-CHECKLIST.md](RUBRIC-CHECKLIST.md) for the older Week 2/3 snapshot). "Verified" means compiled and/or covered by the tests listed. Anything that needs packages or services that were not available when this was prepared is marked **Not run**.

## Part A: Couchbase Lite offline store (`src/ApexPost.Courier.Offline`)

| Requirement | Where | Status |
|---|---|---|
| Uses the real **default collection** | `CourierDatabase.DefaultCollection` → `Database.GetDefaultCollection()` | Implemented, **Not run** (needs Couchbase Lite package) |
| SQL++ strings with **named parameters** | `CouchbaseScanRepository` → `Database.CreateQuery("SELECT ... WHERE syncStatus = $status")` + `Parameters` | Implemented, **Not run** |
| Value indexes | `CourierDatabase` creates indexes on tracking number / sync status / scannedAtUtc | Implemented, **Not run** |
| Several change listeners, each removable | `CourierDatabase.AddChangeListener` returns a token; tokens kept in a list | Implemented, **Not run** |
| Corrupt documents are not hidden | `DeserializeFrom...` logs and reports instead of `catch { return null; }` | Implemented, **Not run** |
| Failed uploads are retried | `OutboxService.ProcessPendingAsync` processes `Pending` and `Failed` | Verified: `OutboxServiceTests` |
| Design note matches the code | [OFFLINE-DESIGN.md](../OFFLINE-DESIGN.md) (no ETag/version claims; idempotency by scan id) | Done |
